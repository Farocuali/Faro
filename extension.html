Extensión FARO

FARO completo en tu navegador, más codificar dentro de Google Docs y capturar páginas web. Gratis, sin cuentas y sin servidores.

Cada una guarda su propio proyecto en el navegador. Para pasar un proyecto de la web a la extensión, mirá «Pasar mi proyecto de FARO web» más abajo.

Primeros pasos

1. Abrir FARO completo

Hacé clic derecho en el ícono del faro, en la barra del navegador → Abrir FARO. Se abre en una pestaña propia. Con un clic normal se abre el panel lateral, con las capturas web y la bibliografía.

2. Conectar Google (opcional)

En FARO, tocá el botón G (arriba a la derecha) → Conectar con Google y elegí tu cuenta. Así los códigos se guardan dentro de tus Docs y podés respaldar el proyecto en tu Drive. Sin conectar Google, FARO funciona igual, pero los códigos quedan solo en FARO.

3. Codificar en Google Docs

  1. Abrí cualquier Google Doc: abajo a la derecha aparece el botón FARO.
  2. La primera vez, con Google conectado, el panel te ofrece Dar acceso a FARO a este Doc: se abre el selector de Google, elegís ese documento y listo. Se hace una vez por Doc.
  3. Seleccioná un fragmento, copialo (Ctrl+C) y escribí el código en el panel. Queda resaltado con el color del código.
  4. Atajos: Alt+Shift+1…9 aplican tus códigos favoritos. Con el botón ✎ escribís un memo sobre el fragmento.
  5. En FARO, Sincronizar con el Doc trae todo lo codificado a tu proyecto.

4. Capturar páginas web (etnografía digital)

Seleccioná un texto en cualquier página → clic derecho → Enviar a FARO (o Alt+Shift+F). Se guarda con la dirección y la fecha, para citarlo. Lo codificás desde el panel lateral y lo pasás al proyecto.

5. Citar en tu tesis

En el panel de Docs, Citar en tu texto: elegís un código y copiás cualquiera de sus fragmentos como cita lista para pegar, con su fuente y fecha (y con seudónimos, si los cargaste).

Pasar mi proyecto de FARO web a la extensión

  1. En FARO web: Respaldar / Descargar datos. Se descarga un archivo .json.
  2. En la extensión: abrí FARO completo → Importar respaldo y elegí ese archivo.

Instalarla a mano (para probar)

Chrome, Edge o Brave

  1. Descargá y descomprimí el paquete de FARO para Chrome.
  2. Abrí chrome://extensions (en Edge: edge://extensions; en Brave: brave://extensions).
  3. Activá el Modo de desarrollador → Cargar descomprimida → elegí la carpeta faro.
  4. No borres ni muevas esa carpeta: el navegador usa la extensión desde ahí.

Firefox

  1. Abrí about:debugging#/runtime/this-firefox → Cargar complemento temporal… → elegí faro-firefox.xpi.
  2. Firefox la quita al cerrarse: para tenerla siempre, instalala desde la tienda cuando esté disponible.

Privacidad

FARO no tiene servidores, cuentas, publicidad ni analítica. Tu proyecto queda en tu navegador y, si lo elegís, en tu propio Drive. Con Google, FARO solo puede ver los archivos que crea y los Docs que vos elegís; no ve el resto de tu Drive. Política de privacidad completa.

Preguntas frecuentes

¿Cuesta algo?

No. FARO es gratuito y de código abierto (licencia MIT). Las funciones de IA son opcionales y usan tu propia clave gratuita de Gemini.

Google me dice «Google no verificó esta app»

Puede aparecer mientras FARO está en etapa de prueba. Tocá Avanzado → Ir a FARO. El permiso que pide es solo para los archivos que uses con FARO.

¿Qué ve FARO de mi Drive?

Solo la carpeta «FARO» que él mismo crea, sus respaldos y los Docs a los que le das acceso uno por uno con el selector de Google. Nada más.

¿Cómo desconecto mi cuenta?

Desde el botón G de FARO → Desconectar, o en myaccount.google.com/permissions.

¿Puedo perder mi trabajo?

Tu proyecto vive en el navegador: si borrás los datos del navegador o desinstalás la extensión, se pierde. Hacé respaldos seguido (Respaldar / Descargar datos) o activá la copia automática en Drive.

¿Funciona en el celular?

En Firefox para Android, sí. La app de Google Docs para celular no muestra extensiones, así que para codificar dentro de los Docs conviene usar la computadora.

Getting started

1. Open full FARO

Right-click the lighthouse icon in the browser toolbar → Open FARO. It opens in its own tab. A left click opens the side panel (web captures and bibliography).

2. Connect Google (optional)

In FARO, click the G button (top right) → Connect with Google and pick your account. Codes are then stored inside your Docs and you can back up the project to your Drive. Without Google, FARO still works, but codes stay in FARO only.

3. Code in Google Docs

  1. Open any Google Doc: the FARO button appears at the bottom right.
  2. The first time, with Google connected, the panel offers Give FARO access to this Doc: Google's picker opens, you choose that document and you're done. Once per Doc.
  3. Select a fragment, copy it (Ctrl+C) and type the code in the panel. It gets highlighted in the code's colour.
  4. Shortcuts: Alt+Shift+1…9 apply your favourite codes. The ✎ button adds a memo to the fragment.
  5. In FARO, Sync with the Doc brings everything coded into your project.

4. Capture web pages (digital ethnography)

Select text on any page → right-click → Send to FARO (or Alt+Shift+F). It is saved with its address and date for citation. Code it from the side panel and send it to the project.

5. Cite in your thesis

In the Docs panel, Cite in your text: pick a code and copy any of its fragments as a ready-to-paste quote with source and date (pseudonymised if you set pseudonyms).

Move my project from FARO web

  1. In FARO web: Backup / Download data. A .json file is downloaded.
  2. In the extension: open full FARO → Import backup (Importar respaldo) and pick that file.

Install it by hand (to try it)

Chrome, Edge or Brave

  1. Download and unzip the FARO package for Chrome.
  2. Open chrome://extensions (Edge: edge://extensions; Brave: brave://extensions).
  3. Turn on Developer mode → Load unpacked → choose the faro folder.
  4. Don't delete or move that folder: the browser runs the extension from it.

Firefox

  1. Open about:debugging#/runtime/this-firefox → Load Temporary Add-on… → choose faro-firefox.xpi.
  2. Firefox removes it when it closes: to keep it, install it from the store once available.

Privacy

FARO has no servers, accounts, ads or analytics. Your project stays in your browser and, if you choose, in your own Drive. With Google, FARO can only see the files it creates and the Docs you choose; it can't see the rest of your Drive. Full privacy policy.

FAQ

Does it cost anything?

No. FARO is free and open source (MIT licence). AI features are optional and use your own free Gemini key.

Google says “Google hasn't verified this app”

It may appear while FARO is in its testing stage. Click Advanced → Go to FARO. The permission it asks for only covers the files you use with FARO.

What can FARO see in my Drive?

Only the “FARO” folder it creates, its backups and the Docs you give it access to one by one with Google's picker. Nothing else.

How do I disconnect my account?

From FARO's G button → Disconnect, or at myaccount.google.com/permissions.

Can I lose my work?

Your project lives in the browser: clearing browser data or uninstalling the extension deletes it. Back up often (Backup / Download data) or turn on automatic copies to Drive.

Does it work on phones?

On Firefox for Android, yes. The Google Docs phone app doesn't show extensions, so coding inside Docs works best on a computer.
