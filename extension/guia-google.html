Conectar FARO con Google

Se hace una sola vez, en unos 15 minutos. Creás un acceso propio y gratuito en Google Cloud: así tus documentos van directo de tu cuenta a FARO, sin pasar por ningún servidor de terceros. Google cambia a veces los nombres de los menús: si algo no coincide exactamente, buscá el más parecido.

  1. Crear el proyecto

    Entrá a console.cloud.google.com con tu cuenta de Google, creá un proyecto nuevo llamado FARO y seleccionalo arriba a la izquierda.

  2. Habilitar las APIs de Drive, Docs y el selector

    Abrí estos tres enlaces (con el proyecto FARO seleccionado) y tocá Habilitar en cada uno:

    • Google Drive API
    • Google Docs API
    • Google Picker API (el selector con el que cada persona le da acceso a FARO a un Doc)

  3. Configurar la pantalla de consentimiento

    Andá a Google Auth Platform y tocá Comenzar:

    • Nombre de la app: FARO. Correo de asistencia: el tuyo.
    • Público: Externo.
    • Datos de contacto: tu correo. Aceptá la política y tocá Crear.

    Después, en Público (Audience), bajá hasta Usuarios de prueba y agregá tu propio correo de Google.

  4. Crear el Client ID

    En Clientes → Crear cliente:

    • Tipo de aplicación: Aplicación web. Nombre: FARO extensión.
    • En Orígenes autorizados de JavaScript agregá: https://farocuali.github.io
    • En URIs de redireccionamiento autorizados tocá Agregar URI y pegá cada una de estas (la primera sirve para este navegador; la segunda, para tablets y celulares con Firefox):

    Tocá Crear. Google te muestra el ID de cliente: algo como 123456789-abc.apps.googleusercontent.com. Copialo. El número del principio es el número de tu proyecto: el selector lo necesita.

  5. Crear la clave del selector

    En Credenciales tocá Crear credenciales → Clave de API y después Editar esa clave:

    • Restricciones de aplicación: Sitios web, y agregá https://farocuali.github.io/* y https://docs.google.com/* (Google exige este último para el selector).
    • Restricciones de API: elegí solo Google Picker API.

    Guardá y copiá la clave (empieza con AIza).

  6. Pegar todo en FARO y conectar

    Abrí FARO, tocá el botón G de arriba a la derecha, pegá el Client ID y la clave del selector, y tocá Guardar. Después, Conectar con Google.

    Google va a avisar que «Google no verificó esta app». Es normal mientras la app está en modo de prueba. Tocá Avanzado → Ir a FARO y aceptá el permiso: ver y editar solo los archivos que uses con FARO.

    La primera vez que codifiques un Doc con Google conectado, el panel de FARO te ofrece «Dar acceso a FARO a este Doc»: se abre el selector de Google con ese documento, lo elegís y listo. Se hace una vez por Doc.

Qué puede ver FARO

FARO usa el permiso por archivo de Google: solo puede ver los archivos que crea (la carpeta «FARO», los respaldos y los Docs de resultados) y los Docs a los que vos le das acceso con el selector. En esos Docs lee el texto y guarda los códigos (como rangos con nombre), junto con el resaltado. No puede ver el resto de tu Drive. Podés desconectar la cuenta en cualquier momento desde el botón G, o desde myaccount.google.com/permissions.

Cuando la publiques en la Chrome Web Store

La tienda le asigna a la extensión un ID nuevo. Volvé al cliente del paso 4 y agregá una segunda URI con ese ID: https://ID-DE-LA-TIENDA.chromiumapp.org/. Como FARO usa solo el permiso por archivo, que Google clasifica como no sensible, para abrirla a todo el mundo alcanza con pasar la app a «En producción» en Google Auth Platform (puede que Google pida verificar el nombre y el logo de la marca).

Connect FARO to Google

You do this once, in about 15 minutes. You create your own free access in Google Cloud: your documents go straight from your account to FARO, without passing through any third-party server. Google sometimes renames its menus: if something doesn't match exactly, pick the closest option.

  1. Create the project

    Go to console.cloud.google.com with your Google account, create a new project called FARO and select it at the top left.

  2. Enable the Drive, Docs and Picker APIs

    Open these three links (with the FARO project selected) and click Enable on each:

    • Google Drive API
    • Google Docs API
    • Google Picker API (the picker people use to give FARO access to a Doc)

  3. Set up the consent screen

    Go to Google Auth Platform and click Get started:

    • App name: FARO. Support email: yours.
    • Audience: External.
    • Contact information: your email. Accept the policy and click Create.

    Then, under Audience, scroll to Test users and add your own Google email.

  4. Create the Client ID

    Under Clients → Create client:

    • Application type: Web application. Name: FARO extension.
    • Under Authorized JavaScript origins add: https://farocuali.github.io
    • Under Authorized redirect URIs click Add URI and paste each of these (the first works for this browser; the second, for tablets and phones with Firefox):

    Click Create. Google shows you the Client ID: something like 123456789-abc.apps.googleusercontent.com. Copy it. The leading number is your project number: the picker needs it.

  5. Create the picker key

    Under Credentials click Create credentials → API key, then Edit that key:

    • Application restrictions: Websites, and add https://farocuali.github.io/* and https://docs.google.com/* (Google requires the latter for the picker).
    • API restrictions: choose only Google Picker API.

    Save and copy the key (it starts with AIza).

  6. Paste everything in FARO and connect

    Open FARO, click the G button at the top right, paste the Client ID and the picker key, and click Save. Then Connect with Google.

    Google will warn that “Google hasn't verified this app”. That's expected while the app is in testing mode. Click Advanced → Go to FARO and accept the permission: see and edit only the files you use with FARO.

    The first time you code a Doc with Google connected, the FARO panel offers “Give FARO access to this Doc”: Google's picker opens with that document, you choose it and that's it. Once per Doc.

What FARO can see

FARO uses Google's per-file permission: it can only see the files it creates (the “FARO” folder, backups and result Docs) and the Docs you give it access to with the picker. In those Docs it reads the text and stores the codes (as named ranges) along with the highlighting. It can't see the rest of your Drive. You can disconnect at any time from the G button, or at myaccount.google.com/permissions.

When you publish it on the Chrome Web Store

The store gives the extension a new ID. Go back to the client in step 4 and add another URI with that ID: https://STORE-ID.chromiumapp.org/. Since FARO only uses the per-file permission, which Google classifies as non-sensitive, opening it to everyone means switching the app to “In production” in Google Auth Platform (Google may ask to verify the brand name and logo).
